# 50→60 PROJECT

50代の10年間で達成したい目標や継続したい習慣を記録・管理・育成するためのパーソナル目標管理Webアプリケーション（PWA対応）です。

---

## ✨ 主な機能

1. **暗号化ローカル保存 (PINロック)**
   * 個人プライバシーに配慮し、端末内（`localStorage`）にAES-GCM 256bit方式で暗号化して保存します。
   * 初回設定したPINで解除します。

2. **繰り返し習慣・ルーティン管理（Weekly / Monthly / Yearly）**
   * 「ボクシング（週1）」「ジム（週4）」「読書（月1冊）」「健康診断（年1回）」などの定期習慣を設定可能。
   * 画面上部の**「🔄 定期習慣・ルーティンタスク」**エリアから、ワンタップで「今期分完了」を記録できます。

3. **カテゴリー管理・並び替え機能**
   * カテゴリー（ジャンル）の追加・編集・削除に加えて、**「↑」「↓」ボタンによる表示順序の入れ替え**が可能です。
   * 目標が残っているカテゴリーを削除する際は、安全な目標移動を促す設計になっています。

4. **最重要TOP10（50歳の1年目）**
   * 「50歳の1年目」フィルター選択時、今年度最優先で達成したい10個の重要目標カードを上部に一覧表示します。

5. **写真＆達成記録機能**
   * 目標達成時に達成日、一言メモ、写真を記録可能です。

6. **Excel / スプレッドシート用 CSVデータ出力**
   * ヘッダーの**「📊 CSV」**ボタンから、全目標データを文字化けなし（BOM付きUTF-8）でダウンロードできます。

7. **スマホ向けPWA（アプリ化）対応**
   * ホーム画面に追加して独立したアプリ（PWA）として起動が可能です。

## 📂 構成ファイル一覧

リポジトリ直下に以下の**6つのファイル**を配置することで、スマホでのアプリインストール機能が有効化されます。

| ファイル名 | 役割 |
| :--- | :--- |
| **`index.html`** | アプリ本体（デザイン・ロジック・暗号化処理） |
| **`manifest.json`** | アプリ設定ファイル（名前・アイコン・起動モード） |
| **`sw.js`** | PWA動作・オフライン対応用のService Worker |
| **`icon-192.png`** | アプリ用アイコン（192×192px） |
| **`icon-512.png`** | アプリ用アイコン（512×512px） |
| **`README.md`** | プロジェクト仕様書（本ファイル） |

## 📱 PWA（ホーム画面へのインストール）方法

### Android (Google Chrome / Samsung Internet)
1. ブラウザで `https://<ユーザー名>.github.io/<リポジトリ名>/` にアクセスします。
2. 右上の **「メニュー（︙）」** をタップします。
3. **「アプリをインストール」** または **「ホーム画面に追加」** を選択します。

### iOS (Safari)
1. Safariでブラウザを開きます。
2. 画面下部の **「共有ボタン（□に↑）」** をタップします。
3. **「ホーム画面に追加」** を選択します。

---

## 🔒 セキュリティとデータについて
* 本アプリはサーバーへ個人データを送信しません。すべてご利用の端末内に暗号化して保持されます。
* PINコードを忘れた場合、復元することはできませんのでご注意ください。
* 端末変更やバックアップの際は、「📊 CSV」機能で定期的に保存しておくことを推奨します。
