50→60 PROJECT 簡単PIN版

使い方
1. index.html をブラウザで開く
2. 初回のみ6桁以上のPINを設定
3. 次回から同じPINでログイン

今回の追加機能
- 上部の達成数・達成率・カテゴリー・検索を固定
- 下の目標一覧だけスクロール
- 各目標を「未着手 / 挑戦中 / 達成！」の3段階で管理
- 達成時に達成日・一言メモ・写真を保存
- 写真は自動縮小してから暗号化保存
- 旧データは自動で新しい3段階へ移行

注意
- PINを忘れると復元できません。
- ブラウザのサイトデータを削除すると保存データも消えます。
- 写真を大量に保存するとブラウザ容量上限に達する可能性があります。
